# FFXIV TTRPG: Stormblood FATEs

A Foundry Virtual Tabletop adventure module containing a connected series of FATEs from the FFXIV TTRPG Stormblood Advanced Rulebook.

## Contents

The `Stormblood FATEs` adventure compendium contains The Dataqi Chronicles:

1. Duty & Deprivation
2. Distress
3. Diplomacy

The adventure includes prepared scenes, grid-aligned encounter maps, actors, tokens, abilities, traits, and GM reference journals for running the complete three-FATE sequence.

## Requirements

- Foundry Virtual Tabletop 14.370 or newer
- FFXIV TTRPG system 6.2.0 or newer

## Installation

In Foundry VTT, open the Add-on Modules tab, select **Install Module**, and paste this manifest URL:

```text
https://github.com/AxeBane/ffxiv-ttrpg-stormblood-fates/releases/latest/download/module.json
```

Enable **FFXIV TTRPG: Stormblood FATES** in your world after installation.

## Importing the Adventure

1. Open **Compendium Packs** in your world.
2. Open **Stormblood FATEs**.
3. Select **The Dataqi Chronicles**.
4. Choose **Import Adventure** and review the import options before confirming.

Importing creates the prepared actors, items, journals, and scenes in the current world. Back up an existing world before importing if it contains documents with matching IDs.
